# Pokémon Gen 2 Gold/Silver Localized Version – Update History

## 2025.10.01 v1.1.0 Update Details
- [Pokémon Gold & Silver]:
	1.	Version 1.1.0 adds compatibility with the exploit method used by the third-party tool [Pokémover for GBA](https://github.com/enler/pokemover_for_gba). The multiboot method was already supported in the v1.0.0 localized release.
	2.	Adjusted the translations of certain proper nouns and terminology.
	3.	Fixed some incorrect translations.
	4.	The version number shown in the game settings has been updated to v110.
